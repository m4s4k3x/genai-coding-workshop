# 研修ワークショップ：AI と共に開発する WeatherInsight - 天気データトラッキングシステム（Rails API & RSpec & TypeScript CLI）

1. ワークショップ概要
   本ワークショップでは、最新の開発ツールと AI アシスタントを活用し、実用的な天気データ管理アプリケーション（バックエンド API ＋ CLI クライアント）を開発します。OpenWeather API から取得した世界各地の気象情報をデータベースに保存・分析する実践的な Rails API を構築し、その API に対する自動テスト(RSpec)を作成します。さらに、作成した API と対話するためのコマンドラインインターフェース(CLI)ツールを TypeScript で開発します。

7. ワークショップシナリオ：「WeatherInsight」アプリケーション開発
   世界各地の現在の天気データと予報データを取得し、時系列で保存・分析できるアプリケーションを開発します。

バックエンド API (Rails):

都市名または座標から天気データを取得し、DB に記録するエンドポイント
保存済みの天気データを検索・表示するエンドポイント
統計情報（気温の平均値、最高/最低など）を計算するエンドポイント

CLI クライアント (TypeScript):

track <都市名> コマンドで指定した都市の天気データを取得・保存
view [都市名] コマンドで保存済みデータを一覧表示
stats <都市名> [期間] コマンドで統計情報を表示

9. AI アシスタントの活用ポイント

モデル設計支援:
OpenWeather API のレスポンスから必要なデータを保存するための
Rails モデル設計を提案してください。都市情報、気温、湿度、風速などの
データを効率的に保存したいです。

API 連携コード生成:
HTTParty を使って OpenWeather API から都市名「Tokyo」の現在の天気を
取得する Rails コードを書いてください。API キーは環境変数から取得します。

RSpec テスト生成:
WeatherRecordsController の create アクションに対する RSpec テストを
書いてください。外部 API へのリクエストはモックします。

TypeScript CLI 設計:
yargs 使用して OpenWeather 連携 CLI を設計したいです。
track, view, stats の 3 つのコマンドがあり、それぞれ都市名を引数に
取ります。基本的なコマンド定義コードを書いてください。
